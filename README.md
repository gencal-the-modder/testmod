# Test Mod that allows user to send messages to server's inner postgres database

Use "R" key (by default) while in game to open screen from which you can send message to server

Use docker compose file to deploy your PostgresSQL server

Oonce mod is launched, it will generate config file, in which you can specify your own info and credentials for your database

By default, credentials in docker-compose and default config values match
